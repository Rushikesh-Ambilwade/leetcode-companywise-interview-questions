# LeetCode Company-Wise Interview Questions

A comprehensive collection of **Data Structures and Algorithms (DSA) interview questions**, organized company-wise to help students and software engineering aspirants prepare for technical interviews and placement opportunities.

## About This Repository

This repository provides a centralized collection of LeetCode coding interview questions asked by different companies.

Questions are organized into separate company folders, making it easier for students to prepare for their target companies without searching through multiple sources.

Each question includes relevant information such as:

- LeetCode Question Number
- Problem Name
- Direct LeetCode Problem Link
- Difficulty Level (Easy, Medium, Hard)
- Acceptance Rate
- Interview Frequency

Questions are also categorized based on their recency to help users prioritize their preparation.

## Features

- **Company-Wise Organization:** Separate folders for different companies to make navigation easier.
- **Question Recency:** Questions categorized according to different time periods.
- **LeetCode Question Numbers:** Easily identify the original coding problems.
- **Direct Problem Links:** Access the original LeetCode problem with a single click.
- **Difficulty Level:** Identify Easy, Medium, and Hard questions.
- **Acceptance Rate:** Understand the percentage of accepted submissions.
- **Interview Frequency:** Identify how frequently questions appear in interviews.
- **DSA Preparation:** Practice company-specific coding questions for technical interviews and placements.

## Question Categories

Questions are organized into the following time-based categories:

| Category | Description |
|---|---|
| Last 30 Days | Questions recently asked in interviews within the last 30 days. |
| Last 3 Months | Questions reported in interviews within the last 3 months. |
| Last 6 Months | Questions reported in interviews within the last 6 months. |
| Last 1 Year | Questions reported in interviews within the last year. |
| All Questions | Complete collection of available questions for that company. |

These categories help students identify recently asked questions and understand interview trends over different periods.

## How to Use This Repository

Follow these simple steps to prepare for your target company:

1. Browse the repository.
2. Find and select your target company.
3. Open the respective company folder.
4. Select a question category based on its recency.
5. Check the question number, difficulty, acceptance rate, and frequency.
6. Click the LeetCode link to open the original problem.
7. Practice solving the question and improve your problem-solving skills.

## Getting Started

Clone this repository to your local machine:

```bash
git clone https://github.com/Rushikesh-Ambilwade/leetcode-companywise-interview-questions.git
```

Navigate to the project directory:

```bash
cd leetcode-companywise-interview-questions
```

## Recommended Preparation Strategy

- Start with Easy-level questions to strengthen your fundamentals.
- Practice important DSA topics such as Arrays, Strings, Linked Lists, Stacks, and Queues.
- Move towards Trees, Graphs, Binary Search, Greedy Algorithms, and Dynamic Programming.
- Prioritize questions from the Last 30 Days and Last 3 Months categories.
- Explore frequently asked questions for your target company.
- Practise consistently and analyze your problem-solving approach.
- Revisit difficult questions and improve your solutions.
